Help

Setting up, and what to do when something looks wrong.

Set it up
  1. On Account, enter your Riot ID, pick your region, and paste a Riot API key.
  2. On Overlay, hit Copy URL.
  3. In OBS or Streamlabs, add a Browser Source, paste the URL, and set the size to 400 × 130.
  4. Play. The card updates itself after every game.
Send a report

Card not showing up right on stream? Open it once in OBS, wait a few seconds, then copy the report and send it along — it describes what went wrong on this PC. Your API key is never included.
